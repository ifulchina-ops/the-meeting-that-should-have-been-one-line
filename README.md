One sentence that could have replaced an entire pointless meeting:

> Nine people spent an hour deciding nothing, so I decided for everyone: we're not doing it, and this sentence was the meeting.

Nine people, one hour, zero decisions — so the decision makes itself, and the sentence is the meeting. It needs no context: anyone who has sat through a useless meeting has lived this one.

## Run it

```sh
node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), gated to 1–200 characters on a single line. No network, no clock, no randomness — the same line every run.
